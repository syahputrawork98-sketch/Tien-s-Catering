# 00 - Project Overview

## Ringkasan

Tien's Catering adalah aplikasi pemesanan makanan dan catering untuk kebutuhan harian dan acara, dengan fokus operasional awal di lingkungan Pemkot Cimahi.

## Konteks Bisnis

- Bisnis berasal dari usaha catering keluarga.
- Operasional utama melayani area Pemkot Cimahi dan sekitarnya.
- Tujuan digitalisasi: mempermudah pemesanan, pencatatan, dan pengantaran.

## Masalah Utama

- Lokasi kantin berpindah lebih jauh dari area kerja.
- Pegawai membutuhkan cara pesan makanan yang lebih praktis, cepat, dan terstruktur.

## Target Pengguna Awal

- Pegawai/personal Pemkot Cimahi.
- Instansi/dinas/bidang.
- Publik/perusahaan luar.

## Fase Project Saat Ini

- Project masih **frontend-first / UI-only prototype**.
- Backend final, integrasi auth production, dan database production belum masuk fase implementasi saat ini.
