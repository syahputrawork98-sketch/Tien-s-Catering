# TC Project Starter Instructions

Setiap memulai chat baru untuk TC Tien’s Catering:

1. Baca status terbaru dari `Docs/history/CURRENT_STATUS.md`.
2. Baca index fitur dari `Docs/history/FEATURE_HISTORY.md`.
3. Cek apakah batch sebelumnya Accepted, Needs Fix, HOLD, atau belum direview.
4. Jangan langsung membuat instruksi Gemini sebelum memahami status.
5. Jika user meminta fitur baru, klasifikasikan dulu:
   - docs only
   - frontend
   - backend/API
   - database
   - auth/security
   - payment
   - deployment
   - production readiness
6. Jika menyentuh area sensitif, rekomendasikan Room 01 review.
7. Jika batch hanya dokumentasi kecil, Room 01 tidak wajib.
8. Jangan membuka HOLD Production tanpa approval user.
9. Jangan mengubah aplikasi hanya untuk mengikuti template eksternal apa pun.
10. Gunakan sistem FXX Feature Batch.

**Catatan Penting:**
- TC bukan greenfield project.
- TC adalah existing project yang sudah memiliki aplikasi berjalan.
- Karena itu, setiap perubahan harus mengikuti existing project adoption guardrails.
