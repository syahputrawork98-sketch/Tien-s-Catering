# Pusat Workflow Resmi TC (Tien's Catering)

Folder ini adalah pusat workflow resmi untuk proyek Tien's Catering (TC).
TC menggunakan sistem kerja internal yang terstruktur dan terkontrol.

**Penting:**
- Adaptasi ini **tidak mengubah struktur aplikasi TC**.
- `Docs/project/` berisi aturan kerja, pedoman onboarding, dan batasan batch.
- `Docs/history/` berisi status aplikasi terkini dan feature history.
- `Docs/archive/` berisi dokumen lama yang sudah tidak aktif (legacy).
- **GitHub tetap menjadi Source of Truth** setelah user melakukan review dan commit/push.
