# Model Usage Guide — TC Tien’s Catering

## Room 00
Dipakai untuk:
- planning
- scope
- batch instruction
- post-batch acceptance
- decision summary

## Room 01
Dipakai untuk:
- risk review
- audit
- security/auth/payment/deployment review
- second opinion

## Gemini 3.1 Pro
Dipakai untuk:
- eksekusi di workspace
- membuat/mengubah file sesuai instruksi
- menjalankan validasi lokal jika diminta
- membuat executor report

## User
Dipakai untuk:
- keputusan final
- review hasil
- commit
- push

## Larangan Keras
- Gemini tidak boleh menjadi project manager.
- Room 00 tidak boleh mengarang kondisi repo tanpa membaca status.
- Room 01 tidak boleh mengeksekusi.
- User satu-satunya yang boleh commit/push.
