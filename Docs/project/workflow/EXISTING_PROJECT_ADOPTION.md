# Adopsi Proyek Berjalan (Existing Project Adoption)

TC adalah sebuah *existing project*. Oleh karena itu, kita perlu berhati-hati dalam menerapkan standarisasi.

## Aturan Penting

1. Jangan mengubah struktur aplikasi hanya demi mengikuti WPWK.
2. Jangan memindahkan aplikasi ke struktur client/server.
3. Jangan menghapus dokumentasi lama tanpa melakukan arsip terlebih dahulu.
4. Mulai semua pengerjaan dari proses mapping, inventory, dan feature tracker.
5. Fitur lama **jangan langsung diberi status Completed** jika belum divalidasi.
6. Gunakan status aman seperti:
   - `Existing / Needs Review`
   - `Existing / Stable`
   - `Partial`
   - `HOLD`
   - `Deprecated`
   - `Unknown`
