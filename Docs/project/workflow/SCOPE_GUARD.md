# Batasan Permanen (Scope Guard)

Fitur-fitur dan area berikut berada dalam status **HOLD Production**:

- Payment gateway real
- Auth production final
- RBAC (Role-Based Access Control) final
- Cloud / S3 storage
- e-Faktur / legal tax
- Deployment production final
- Domain / SSL final
- Database migration production

## Aturan Guard

1. Semua area HOLD Production hanya boleh dibuka melalui batch khusus.
2. Harus mendapatkan **approval user**.
3. Harus melewati **review Room 01**.
4. Gemini tidak boleh membuka status HOLD ini secara mandiri.
