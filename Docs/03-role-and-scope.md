# 03 - Role and Scope

## Role Produk Awal

- Konsumen
- Admin
- Super Admin

## Segmentasi Konsumen

- Personal/pegawai.
- Instansi/dinas.
- Publik/perusahaan.

## Cakupan Tugas Admin

- Input menu harian.
- Mengatur stok porsi.
- Melihat pesanan.
- Konfirmasi pesanan.
- Update status pembayaran.
- Update status pengantaran.
- Dapat merangkap pengantaran.

## Cakupan Tugas Super Admin

- Kelola akun/admin operasional.
- Melihat seluruh data lintas role.
- Mengatur kategori konsumen.
- Mengatur setting bisnis/pajak sederhana.
- Melihat laporan global.

## Catatan Konsistensi

Role `CS/USER/ADMIN` di `kanban-master/` adalah kondisi UI lama/current tracking dan belum tentu menjadi role final produk.
