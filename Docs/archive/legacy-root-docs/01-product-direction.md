# 01 - Product Direction

## Arah Produk Utama

- Tien's Catering difokuskan sebagai aplikasi pemesanan makanan/catering untuk Pemkot Cimahi dan segmen terkait.
- Menu harian berubah setiap pagi.
- Setiap menu harian memiliki stok porsi.
- Tersedia paket catering untuk acara/rapat.
- Delivery order dilakukan oleh tim/admin Tien's Catering.

## Catatan Operasional Awal

- Pajak belum dibuat kompleks.
- Pada fase awal, pajak cukup diposisikan sebagai pengaturan/arah opsional di level bisnis.

## Batasan Dokumen

Dokumen ini adalah acuan arah produk, bukan instruksi untuk implementasi backend besar.  
Implementasi backend/auth/database/payment gateway production belum menjadi scope eksekusi saat ini.
